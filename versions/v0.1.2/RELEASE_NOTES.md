## What's new
- **No more endless waiting:** an AI that stops replying, a stuck screen step or a slow request now ends with a clear message instead of spinning forever.
- **Nothing happens twice:** computer use won't start the same task twice or send the same thing twice, each approval is used once, and double-clicks no longer start a task or run twice.
- **Honest results:** if a debate's final answer can't be written, or part of a team task isn't finished, LetArgue says so instead of showing it as done.
- **Closed mid-reply?** A chat whose answer was cut off by closing the app is marked "Interrupted" so you can ask again.
- **Safer:** only LetArgue's own windows can talk to the app in the background; web pages can't. Large or damaged attachments can't freeze it.
- **Your account:** repeated wrong passwords lock sign-in for 15 minutes; signing out removes your keys from this computer; you're told if saved keys couldn't be restored.
- **Sturdier storage:** your chats are kept safe if the computer crashes or two things save at once.

### Opening it the first time
- **Mac:** open the DMG and drag **LetArgue** to **Applications**. If macOS says it can't check the app, go to **System Settings → Privacy & Security** and click **Open Anyway**.
- **Windows:** if SmartScreen appears, click **More info → Run anyway**.
